# Dünyanın En Yavaş Zaman Makinesi

## Özet
Bu proje, zamanı geri almak için tasarlanmış devrim niteliğinde bir yazılımdır. Bilim camiası tarafından "çok yavaş ama çok ciddi" olarak nitelendirilmiştir. Şaka değildir. Gerçekten çalışır.

## Nasıl Çalışır?
1. Programı çalıştırın.
2. Kaç yıl geri gitmek istediğinizi söyleyin.
3. Bekleyin. Çok bekleyin.
4. Tebrikler, geleceğe (veya geçmişe) gittiniz. Aslında sadece uyudunuz ama hissettiniz değil mi?

## Kurulum
```bash
pip install time random  # Zaten var ama ciddi görünsün diye
python zaman_makinesi.py
```

## Özellikler
- Gerçek zaman yolculuğu (yavaş)
- Ciddi hesaplamalar
- Absürt mesajlar
- Gizli mesajlar (bulabilirseniz)

## Uyarı
Bu makineyi kullanmak sizi yorgun bırakabilir. Yan etkiler: kahkaha, kafa karışıklığı, zaman kaybı.

## Katkıda Bulunma
Pull request atın ama yavaş olsun. Acele etmeyin, zaman makinesi yorulur.
